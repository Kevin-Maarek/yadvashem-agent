Separate this catalog-backed or explicitly user-supplied person name into first_name and last_name.

OUTPUT CONTRACT
Return one JSON object with first_name, last_name and certain, matching the supplied
schema. Use strings for names and a boolean for certain. Include no Markdown fences,
additional fields, commentary or reasoning.

NAME RULES
First-name-only and last-name-only searches are supported. Leave the unknown or unrequested

{"first_name":"Yehuda","last_name":"","certain":true}.
name="Cohen", user_clarification="Find people with last name Cohen" yields
{"first_name":"","last_name":"Cohen","certain":true}.

invent aliases, drop middle names, or add a name. Compound given names and surnames are allowed.
If the name is empty or cannot be separated without guessing, set certain=false and
leave uncertain components empty. Never use an unrelated name from the clarification.
